# Synthwave Drive project specification

Topic 13 is an interactive neon driving scene with a scrolling grid, steerable car, low-poly mountains, gradient sky and striped sun. The authoritative specification and individual step-by-step tasks are maintained together in [AGENTS.md](AGENTS.md). This companion avoids duplicating an outdated specification.

The current local framework implements the road, indexed rendering, cameras, keyboard/mouse controls and FPS/help. Car hierarchy, environment and two-light shading remain pending. See [requirements and evidence](docs/requirements.md) for the R1–R8 mapping, [README](README.md) for actual controls/build, and [PLAN](PLAN.md) for the schedule.

All members commit and publish personally. AI must not stage, commit, push, tag, create PRs or otherwise modify GitHub.
